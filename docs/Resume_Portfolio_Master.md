## 🚀 Key Projects for Remote Applications

### 1. **SHAME Desktop & Mobile** — *Cross-Platform System App*
* **Role Focus:** Desktop Engineer (Rust / Tauri), React/TypeScript Developer  
* **Tech:** Rust, Tauri, TypeScript, React, Vite, Tailwind CSS, Flutter Mobile
* **Key Achievements:**
  - Built a cross-platform desktop application using **Rust (Tauri framework)** for low-overhead native OS interaction paired with a high-performance **React/TypeScript UI**.
  - Developed a mobile companion client in **Flutter** to support cross-device state synchronization and remote user workflows.

### 2. **Suisik (`ai-tutorer`)** — *AI-Powered Tutoring & RAG Platform*
* **Role Focus:** AI / LLM Application Engineer, Full-Stack Engineer  
* **Tech:** Next.js (App Router), React, TypeScript, Python, RAG Architecture, LLMs (Mistral/Llama), Vector Search, PDF/DOCX Parsing
* **Key Achievements:**
  - Architected an EdTech AI platform using **Next.js App Router, TypeScript, and Python**.
  - Built an end-to-end **RAG (Retrieval-Augmented Generation) pipeline** that parses unstructured PDF/DOCX study materials, builds hierarchical embeddings, and extracts topic graphs.
  - Implemented dynamic evaluation engines generating multi-format adaptive quizzes (MCQ, multi-select, true/false) tailored to student proficiency.

### 3. **YAMDUT** — *Distributed Ride-Sharing Platform*
* **Role Focus:** Backend Engineer, WebSockets Developer, Distributed Systems  
* **Tech:** Node.js, Express, WebSockets, Real-time Geolocation, React, Desktop UI
* **Key Achievements:**
  - Engineered backend microservices for a real-time ride-sharing ecosystem serving passenger booking and driver management.
  - Developed **WebSocket-based bidirectional communication protocols** for real-time GPS telemetry, trip status events, and driver matching.
  - Built desktop management dashboards for real-time fleet oversight and transaction logging.

### 4. **Sambandha** — *Cross-Platform Dating & Matchmaking Platform*
* **Role Focus:** Mobile Engineer (Flutter), Real-Time Streaming / WebRTC Developer  
* **Tech:** Flutter, Dart, WebRTC, Firebase, Cloud Functions, GitHub Actions CI/CD
* **Key Achievements:**
  - Developed a full-scale mobile matchmaking app in **Flutter & Dart** supporting high-volume user interactions.
  - Integrated peer-to-peer **WebRTC audio/video calling** for encrypted real-time communication.
  - Built automated **CI/CD pipelines via GitHub Actions** (`flutter_ci.yml`, `release.yml`) for automated building, linting, and app bundle deployment.

### 5. **Models-from-Scratch & Computer Vision Systems**
* **Role Focus:** Computer Vision Specialist, Machine Learning Engineer  
* **Tech:** Python, NumPy, OpenCV, Scikit-Learn
* **Key Achievements:**
  - Implemented core Machine Learning models (Linear/Logistic Regression, Neural Networks, Gradient Descent) using **pure NumPy matrix math** without high-level framework wrappers.
  - Developed real-time video stream monitoring applications using **OpenCV** to estimate facial landmark geometry and detect driver drowsiness in real time.
