## 📋 Overview

**car_price_prediction** is a software project developed by Dibij.

According to the project documentation:

> This project builds a predictive model to estimate the selling price of used cars based on various features such as engine size, mileage, brand, and more.


- **Goal:** Predict used car selling prices using historical data.
- **Dataset:** `car.csv` containing car details from both main and luxury market segments.
- **Tools:** Python, Pandas, Scikit-learn, Seaborn, Matplotlib, and Large Language Models (LLMs) for assistance.

The codebase is built primarily using **Jupyter Notebook**, comprising 18 total files across the repository structure.
