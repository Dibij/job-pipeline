## 📋 Overview

**Essay-Tracker** is a software project developed by Dibij.

According to the project documentation:

> > *A personal writing gym, not a grading system.*

---


Most vocabulary-building tools are passive. You read a word, see its definition, maybe use it in a sentence exercise, and forget it a week later. Flashcard apps optimise for recognition, not production. You end up knowing what a word means when you see it, but you still can't reach for it when you need it.

The codebase is built primarily using **CSS, HTML, Node.js / JavaScript, PowerShell, Python, React, Rust, Shell Script, TypeScript**, comprising 66 total files across the repository structure.
